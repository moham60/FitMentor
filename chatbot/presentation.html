🔀 نظام التوجيه الذكي

Intelligent Query Router

Supabase Only — بيانات شخصية

عند ذكر بيانات المستخدم: "وزني"، "هدفي"، "تدريبي"، "إنبودي"، "سعراتي"

مثال: "كم وزني الحالي؟" → يسحب من جدول body_measurements

Vector Only — معرفة عامة

أسئلة المعرفة: "ما هو"، "كيف"، "الفرق بين"، "فوائد"

مثال: "ما الفرق بين تمارين الكارديو وتمارين المقاومة؟"

Hybrid — مزيج

أسئلة تحتاج بيانات شخصية + معرفة: "خطة لي"، "ماذا آكل"، "كم بروتين"

مثال: "اعمل لي خطة تدريبية حسب وزني وهدفي"

Off-Topic — خارج التخصص

أسئلة خارج مجال اللياقة: سياسة، طقس، أفلام

مثال: "ما حالة الطقس اليوم؟" → رد مهذب بأنه متخصص باللياقة فقط

🧠 محرك RAG الهجين

Hybrid RAG Engine Pipeline

1

التوجيه (Routing)

تحليل الاستعلام عبر keyword scoring لتحديد وضع الاسترجاع: Supabase فقط، Vector فقط، أو Hybrid

⏱ ~5ms
2

بناء السياق (Context Building)

جلب بيانات المستخدم من 23 جدولاً في Supabase: الملف الشخصي، InBody، خطط التمارين، الوجبات، التمارين المسجلة

⏱ ~200ms (مخبأ لمدة 5 دقائق)
3

البحث المتجهي (Vector Retrieval)

تضمين الاستعلام باستخدام Cohere multilingual v3.0 → بحث FAISS (Inner Product) → إعادة ترتيب حسب الصلة

⏱ ~150ms (مخبأ لمدة دقيقتين)
4

تنسيق السياق (Context Assembly)

دمج البيانات المنظمة من Supabase مع الوثائق المسترجعة من المتجهات في قالب LangChain موحد

⏱ ~5ms
5

توليد الرد (LLM Generation)

Cohere command-a-03-2025 مع درجة حرارة 0.35، حد 600 توكن → تنظيف الرد من Markdown

⏱ ~500-1000ms
6

تخزين الرد الكامل في ذاكرة التخزين المؤقت (مدة دقيقتين) مع إضافة أسئلة متابعة مقترحة

💬 سيناريوهات توضيحية

Example Scenarios

🔀 Supabase Only بيانات شخصية
كم وزني الحالي؟ وهل تغيرت نسبة الدهون من آخر فحص InBody؟
وزنك الحالي 85 كجم، وقد سجلت آخر قراءة في 2026-06-15.
نسبة الدهون في الجسم: 22% (انخفاض 1.5% عن الشهر الماضي 👍).
كتلة العضلات: 40 كجم (ثابتة).
استمر في التدريب المنتظم لتحسين تكوين الجسم.
📦 المصادر: profiles | body_measurements | inbody_results
🔀 Vector Only معرفة عامة
ما الفرق بين تمرين Squat و Lunges؟ وأيهما أفضل لبناء العضلات؟
1. Squat: تمرين مركب يستهدف الفخذين، المؤخرة، وأسفل الظهر. يحرق سعرات أكثر وينشط الهرمونات البنائية.
2. Lunges: تمرين أحادي الجانب يحسن التوازن ويستهدف كل ساق بشكل منفرد. يحسّن ثبات المفاصل.
3. الأفضل: استخدم كليهما - Squat للقاعدة الكلية وLunges للتصحيح والثبات.
📚 المصادر: exercise_library | قاعدة المعرفة المتجهية
🔀 Hybrid شخصي + معرفة
سوّي لي خطة تمارين أسبوعية تناسب وزني وهدفي. وزني 85 وهدفي خسارة دهون
بناءً على بياناتك: الوزن 85 كجم، الهدف: خسارة دهون، مستوى النشاط: متوسط.

الخطة الأسبوعية المقترحة:
1. يوم 1 - كارديو: 30 دقيقة جري + 15 دقيقة عدو
2. يوم 2 - مقاومة: Squat 4x12, Bench Press 4x10, Rows 4x10
3. يوم 3 - راحة نشطة: مشي سريع 45 دقيقة
4. يوم 4 - HIIT: 20 دقيقة Tabata
5. يوم 5 - مقاومة: Deadlift 4x8, Pull-ups 4x8, Shoulder Press 4x10
6. يوم 6 - كارديو: سباحة 40 دقيقة
7. يوم 7 - راحة تامة

احتياجك اليومي: 2200 سعرة (خسارة) مع 180 جرام بروتين
🔗 دمج: Supabase (الملف الشخصي) + FAISS (قاعدة التمارين)
🔀 Off-Topic خارج التخصص
أخبرني عن آخر أخبار كرة القدم
أنا متخصص في اللياقة البدنية والتغذية والرياضة فقط. 😊
يمكنني مساعدتك في: التمارين، الحميات الغذائية، تحليل InBody، أو خطط التدريب.

⚡ طبقة التخزين المؤقت

Multi-Tier Caching System

🏠

In-Memory Cache

تخزين مؤقت في الذاكرة المحلية مع قفل غير متزامن (asyncio.Lock)

🧠 الذاكرة المحلية ⚡ بدون شبكة
🔴

Redis Cache (اختياري)

دعم Redis للتخزين الموزع مع fallback تلقائي للذاكرة المحلية إذا كان Redis غير متاح

📡 موزع 🔄 Fallback
نوع التخزين المفتاح مدة الصلاحية التأثير
📦 سياق المستخدم ctx:user:{id} 5 دقائق يقلل استعلامات Supabase بنسبة 95%
🧠 تضمين المتجهات emb:{hash} ساعة واحدة يقلل استدعاءات Cohere API بنسبة 90%
🔎 نتائج البحث vec:search:{hash} دقيقتان استجابات فورية للأسئلة المتكررة
💬 الردود الكاملة rag:response:{hash} دقيقتان استجابة < 100ms للأسئلة المكررة

📊 إجمالي سعة التخزين المؤقت: عدد الإدخالات النشطة يتغير ديناميكياً مع انتهاء الصلاحية التلقائي

✨ المميزات الرئيسية

Key Features

🌐

دعم ثنائي اللغة

يدعم العربية والإنجليزية بطلاقة، مع كشف تلقائي للغة المستخدم والرد بنفس اللغة

🔒

أمان البيانات (RLS)

طريق الوصول إلى البيانات عبر Supabase مع سياسات Row Level Security و RBAC

🎯

تخصيص دقيق

ردود مخصصة بناءً على بيانات InBody الحقيقية، الملف الشخصي، خطط التمارين، والوجبات

📡

بث مباشر (SSE)

يدعم Server-Sent Events لتدفق الردود حرفاً بحرف لتجربة مستخدم سلسة

📥

استيراد ذكي للمحتوى

يدعم استيراد محتوى المواقع الثابتة وتطبيقات SPA عبر Playwright

🔄

إدارة المحادثات

نظام كامل للمحادثات والرسائل مع دعم Supabase وذاكرة محلية كـ fallback

📊

تكامل ML

اتصال بنموذج التعلم الآلي (Model2) للتنبؤات المخصصة والتحليلات المتقدمة

🧹

تنظيف ذكي للردود

يزيل تنسيق Markdown والأحرف الخاصة للحصول على ردود نظيفة وقابلة للقراءة
