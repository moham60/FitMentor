🔀 نظام التوجيه الذكي

🟢 Supabase Only

أسئلة شخصية: "وزني"، "إنبودي"، "هدفي"，
→ بيانات حقيقية من 23 جدول

🔵 Vector Only

أسئلة عامة: "ما هو"، "كيف"، "فوائد"
→ FAISS + Cohere embeddings

🔴 Hybrid

أكثر الأسئلة شيوعاً
→ "خطة لي" / "ماذا آكل" / دمج شخصي + عام

🟡 Off-Topic

خارج التخصص
→ رد مهذب وتوجيه للرياضة

• "النظام يحلل السؤال ويقرر أين يبحث
• لو فيه كلمات مفتاحية شخصية مثل "وزني" → Supabase
• لو سؤال عام عن التمارين → FAISS
• أغلب الأسئلة تكون Hybrid لأن المستخدم يريد خطة تناسبه
• مثال: "اعمل لي خطة" → يجيب بعد ما يعرف وزنه وهدفه من الداتابيز، ثم يبحث عن التمارين المناسبة"
